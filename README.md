# Raser Native ⚡

> High-performance, lightweight, native music player for Desktop & Mobile powered by **Tauri + Rust** with Material You (M3) design.

---

## 🚀 Features

- **Blazing Fast**: Powered by pure Rust audio decoding & streaming engine.
- **Ultra Lightweight**: Tiny installer size (~10MB vs ~120MB Electron) and minimal RAM usage (~40MB vs ~500MB).
- **Pixel-Perfect Material You 3**: Morphing album art covers, dynamic palette extracted from covers, and smooth 120 FPS animations.
- **Cross-Platform**: Windows (`.exe`), Linux (`.AppImage`, `.deb`), and Android (`.apk`).
- **Unified Library**: YouTube Music & SoundCloud streaming, smart cloud sync, and offline playback.

---

## 🛠️ Tech Stack

- **Core / Backend**: Rust (`tauri`, `rodio`, `symphonia`, `tokio`, `reqwest`)
- **UI / Frontend**: HTML5, Vanilla JavaScript, Modern CSS3 with Material 3 design tokens
- **Platform**: Tauri v2
